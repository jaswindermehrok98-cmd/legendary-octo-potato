INSTALLATION

Put UNPLUG on Home.

These steps describe the intended direct-APK distribution flow. Android version and manufacturer UI can change the exact labels you see.

01 — Download

Open the Download page and get the signed APK from the current GitHub Release.

02 — Install

Open the downloaded APK. If Android asks you to allow installation from that source, enable the relevant setting and return to the installer.

03 — Launch

Open UNPLUG LABS® OFFLINE OS.

04 — Complete setup

The first launch should show the one-time setup flow. Grant only the capabilities you want to use. The launcher should remember completed setup and should not repeatedly ask for the same access unless Android reports that it was revoked or the app was reset.

05 — Make it Home

When prompted, use Android's system Home-app flow to select UNPLUG LABS as your Home app.

06 — Configure intentionally

Choose essential apps, notification presentation, limits, focus presets, and optional device locking.

SAFETY

Never sideload a build from an untrusted mirror. For each release, the website should publish a checksum and point back to the canonical GitHub Release.

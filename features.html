FEATURE MAP

The launcher is the product.

Everything below is designed around one goal: keep the phone useful while reducing the number of reasons it can steal your attention.

Home

UNPLUG becomes the Android Home app. Installed applications are discovered dynamically and remain accessible without forcing a traditional grid onto the user.

Inbox

Supported Android notifications can be organized into an intentional inbox. When the source app provides a real reply action, the launcher can surface it; otherwise it gives the user a direct Open App action.

Limits

Create daily limits and temporary sessions for selected applications. Usage measurement relies on Android's supported usage information and can vary by device.

Focus

Start a focused session and simplify the Home experience. The feature is designed around user choice, not coercion.

Device Timer

A device-wide countdown can optionally end by locking the phone when the user has explicitly enabled the required Android capability.

Today's Message

A small offline message library provides a calm daily prompt. No AI call is required for the core experience.

The Read / Drops / Lab

Secondary UNPLUG LABS experiments live inside the launcher without turning the Home screen into a content feed.

Privacy

Core launcher behavior is local-first. Notification contents, usage information, and experimental answers are not designed to be uploaded by default.

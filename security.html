SECURITY

Verify the build.

Every public release should be distributed from the canonical GitHub Release, signed as an Android release artifact, and accompanied by a SHA-256 checksum.

Never commit the signing key

The Android release keystore is a private credential and must remain outside the public repository. Future updates need to be signed with the same release key so Android can recognize them as updates.

Verify the download

Compare the SHA-256 checksum published on the release page with the APK you downloaded.

Report a security issue

Contact the project security address once a real security contact is configured. Until then, this page intentionally does not invent a mailbox.

SECURITY IS PART OF THE RELEASE PROCESS

PRODUCT DEFINITION

OFFLINE OS

UNPLUG LABS® OFFLINE OS is a native Android launcher. It is designed to become the user's Home application and change the default relationship between a person and their phone.

Important: OFFLINE OS is not a replacement for Android itself. It is a launcher running on Android.

Core idea

Use the phone for what you came here to do. Keep communication and useful applications accessible while reducing unnecessary attention switching.

Inside

  • Home / launcher
  • App search and installed-app discovery
  • Notification inbox
  • Supported quick replies
  • Usage and app limits
  • Focus sessions
  • Device timer
  • Today's Message
  • THE READ, DROPS and LAB
